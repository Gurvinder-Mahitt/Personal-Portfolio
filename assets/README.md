# Portfolio assets

Place approved portrait references, video clips and poster frames, project screenshots, and any approved favicon in this folder. Reference them from the site using paths relative to `index.html` (for example, `assets/hero-scene-poster.webp`).

`gurvinder-portrait.jpg` is a cinematic treatment based on the portrait-style image supplied in the project. Confirm the likeness before publishing. `hero-mine-atmosphere.jpg`, `project-fulfillment.jpg`, `project-pizza.jpg`, and `project-slope.jpg` are generated editorial images; they provide visual context and are not project screenshots or measured results. Replace them with genuine project media when available. Keep generated video, approved posters, and screenshots in this folder and link them with relative paths.
